Banking Fraud Analytics – SQL Analysis

1. Project Overview

This project analyses banking transactions to identify fraudulent activities and understand transaction patterns using SQL.

2. Project Objective

- Identify fraudulent transactions.
- Compare genuine and fraudulent transactions.
- Analyse transaction amounts.
- Understand fraud patterns in the dataset.

3. Dataset Description

Dataset: Credit Card Transactions

Total Records: 283,726

Columns:

- Time
- V1 to V28
- Amount
- Class

Class Description:

- 0 – Genuine transaction
- 1 – Fraudulent transaction

4. Tools Used

- MySQL
- Visual Studio Code
- SQLTools Extension

5. SQL Analysis Performed

- Total transaction count
- Fraud and genuine transaction counts
- Fraud percentage
- Total fraud amount
- Average transaction amount
- Highest and lowest transaction amounts
- Fraud transactions by amount range
- Comparison of fraud and genuine transactions
- Zero-amount fraud transactions

6. Project Files

- 01_Basic_Analysis.sql
- 02_Fraud_Insights.sql

7. Conclusion

This project helped me understand how SQL can be used to analyse banking transactions, identify fraudulent activities, and generate useful insights from transaction data.
8. Key Findings

Based on the dataset analysis:

- Total transactions: 283,726
- Genuine transactions: 283,253
- Fraudulent transactions: 473
- Fraud percentage: Approximately 0.17%
